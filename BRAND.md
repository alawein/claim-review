# Siftgrain Cite

A citation studio in the Siftgrain family. Cite replaces the displayed Claim Review name while retaining the claim-review repository/package and packet namespace for compatibility. Voice: "Every judgment needs a passage."

The primary user is a RAG evaluation owner who needs to review supplied answers against exact retrieved passages, retain disagreements and share a portable record without uploading source material. Import LangChain/LangSmith-shaped local trace JSON/JSONL, review the keyboard queue, merge independently exported packets and export the native packet or analysis labels.

Original geometry: paired open brackets, two evidence lines and one grain below. brand/logo.svg and brand/wordmark.svg are editable SVG sources authored for this product; no third-party logo assets. MIT license. Type: system sans for reading, Georgia for the display headline, system monospace for offsets and metadata. No downloaded fonts or CDN.

Night palette: indigo #100c1c, surface #211a31, cream #f5eedf, amber #ffc46b, jade focus #72f0d4. Dawn: porcelain #f4f2f7, ink #1a1326, indigo #2b2877. Semantic pass/fail/pending colors have tested text contrast. Calm soft easing, Cartoon spring/sticker geometry, Pixel stepped easing/dither, Lab dense typography share the same semantic colors. Reduced motion and Pause disable nonessential motion.

Naming evidence: docs/name-checks.json records live exact-name GitHub/npm/PyPI/HF checks and web search on 2026-10-13. Spanward was rejected for existing software collisions. Siftgrain returned dictionary usage and no obvious software clash in the limited search; this is not legal clearance, domain availability, registration or a guarantee of uniqueness. No domains were proposed or purchased.
